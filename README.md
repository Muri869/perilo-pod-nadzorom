# PERILO POD NADZOROM 🧺

Komična spletna igrica o sortiranju perila. Šefica ukazuje, Možakar sortira
padajoče perilo v pravi koš, dokler ji ne zmanjka potrpljenja.

**Igraj:** https://muri869.github.io/perilo-pod-nadzorom/

## Kako se igra
- Lovi padajoče perilo v **pravi koš**. Ujem velja le, če si na pravem mestu
  **IN** imaš odprt pravi koš.
- Tri kategorije: **BELO**, **BARVNO**, **OBČUTLJIVO** (barvni obroč okoli kosa
  namigne, kam spada).
- Pazi na **rdečo nogavico**: če jo daš v BELO → ROŽNATA KATASTROFA!

## Tipke
- **← →** ali **A D** — hoja
- **1 · 2 · 3** ali **preslednica** — menjava koša
- Na dotik: gumba ◀ ▶ ob robovih, 🔄 na sredini

## Tehnično
- Ena sama datoteka `index.html` (HTML + CSS + JS).
- Čisti vanilla JS + Canvas 2D, brez knjižnic in brez build koraka.
- Liki in perilo so izrisani z emoji; zvok je generiran proceduralno (Web Audio).

## Razvoj
Igro odpreš z dvoklikom na `index.html`. Spremembe shranjujemo z Gitom in
potiskamo na GitHub; objavljena različica teče na GitHub Pages (zgornji link).
